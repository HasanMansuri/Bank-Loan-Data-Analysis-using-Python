# 🏦Bank Loan Analysis using Python

## Overview
This project focuses on performing an in-depth data analysis on bank loan data to understand lending trends, borrower behavior, and overall loan performance.  
It provides valuable insights into how loans are funded, repaid, and distributed among different borrower groups.  

The analysis is built entirely in Python using Google Colab, leveraging libraries like Pandas, Matplotlib, Seaborn, and Plotly Express for data cleaning, analysis, and visualization.  
The goal is to create a data-driven view of the bank’s lending operations by exploring key factors such as loan purpose, term, employment length, home ownership, and region, helping decision-makers make better financial and risk management strategies.  

This project serves as a practical example of how data analytics and visualization can turn raw financial data into meaningful business insights.

---

## Problem Statement
Banks process a large number of loan applications each month, which makes it difficult to monitor performance, risk, and customer behavior efficiently.  
This project aims to solve that challenge by transforming the loan dataset into clear and measurable insights.  

### The main objectives of this project include:
- Calculating important Key Performance Indicators (KPIs) such as:  
  - Total Loan Applications  
  - Total Funded Amount  
  - Total Amount Received  
  - Average Interest Rate  
  - Average Debt-to-Income (DTI) Ratio  
- Identifying and comparing Good Loans vs Bad Loans based on their repayment status.  
- Visualizing monthly, regional, and categorical loan metrics to identify key trends and patterns.  
- Providing actionable insights to support better decision-making and improve loan portfolio performance.  

---

## Key Insights and Analysis

### 1. Monthly Loan Trends
Line and area charts show month-by-month changes in loan funding, applications, and repayments.  
This helps identify seasonal patterns and business growth trends.

### 2. Regional Loan Distribution
Bar charts visualize which states have the highest total funded and received amounts, allowing analysis of regional lending performance.

### 3. Loan Term Analysis
Donut charts display how loans are distributed across different terms (e.g., 36 or 60 months) and their corresponding funded amounts.

### 4. Employment Length Impact
Bar charts show how borrowers’ employment length affects loan approval, funding, and repayment behavior.

### 5. Loan Purpose Breakdown
Bar charts provide insights into the primary reasons borrowers seek loans — such as debt consolidation, home improvement, or credit card repayment.

### 6. Home Ownership Analysis
Treemap charts visualize how home ownership influences loan applications and repayments, offering a hierarchical view of borrower profiles.

---

## Key Metrics Computed

| Metric | Description |
|--------|-------------|
| Total Loan Applications | Total number of loan applications received during the period |
| Total Funded Amount | Total money disbursed by the bank as loans |
| Total Amount Received | Total repayments collected from borrowers |
| Average Interest Rate | Average loan interest rate across all applications |
| Average DTI Ratio | Average debt-to-income ratio measuring borrower financial health |
| Good vs Bad Loans | Comparison between performing and non-performing loans |
